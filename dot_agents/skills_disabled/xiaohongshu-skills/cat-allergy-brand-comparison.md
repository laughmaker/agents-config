
### 原理科普 — 建立专业信任（10%）

```
先搞懂一个事：猫毛过敏 ≠ 对毛过敏。

真正的元凶是猫唾液中的 Fel d1 蛋白。
猫咪舔毛→蛋白附着在毛发上→扩散到环境→你吸入→过敏反应。

所以解决方案只有3个方向：
① 从猫咪饮食减少Fel d1产生（吃进去）
② 从环境清除Fel d1（喷/吸）
③ 从自身控制症状（吃药/打针）

这篇只讲方向① —— 饮食控制。
```
