# Learning record format

Use this format when persistent progress is warranted. Keep it concise and update it in place.

```markdown
---
topic: <topic>
goal: <observable outcome>
started: <YYYY-MM-DD>
last_session: <YYYY-MM-DD>
status: active
---

# <Topic> learning record

- Target outcome:
- Starting level:
- Time budget and deadline:
- Preferred application:

## Learning map
| Level | Outcome | Milestone | Status |
|---|---|---|---|
| 1 | | | not started |

## Current plan
| Session | Objective | Practice | Completion evidence | Status |
|---|---|---|---|---|
| 1 | | | | not started |

## Concept mastery
| Concept | Status | Evidence | Review trigger |
|---|---|---|---|
| | learning | | |

## Misconceptions and corrections
- Misconception:
  - Correction:
  - Recheck:

## Session log
### <YYYY-MM-DD> - Session <N>
- Objective:
- Work completed:
- Evidence:
- Feedback:
- Mastery changes:
- Next action:

## Review sheet
- Mental model:
- Key rules or steps:
- Practical example:
- Common traps:
- Quick recall questions:
```

Rules:

- Record observable evidence, not unsupported confidence scores.
- Append new session-log entries; update summary tables in place.
- Keep prior misconceptions when they are still useful for review.
- Never mark `mastered` solely because the learner read an explanation.
- If the goal or time budget changes, update the constraints and regenerate only the affected plan rows.
