# Design Rule

## Overview
Use this skill to apply a reusable design system built from four visual languages:

1. Point: decide the first visual focus.
2. Line: control reading path and attention movement.
3. Shape: create recognition, grouping, meaning, and memory.
4. Form: build spatial hierarchy, foreground/background, depth, and breathing room.

The full reference lives in `references/design-principles.md`. Read it when the task needs detailed guidance, a full checklist, a design review, or a reusable artifact. For quick answers, apply the condensed workflow below.

## Core Workflow
When designing or reviewing a PPT, webpage, poster, brand visual, or graphic layout:

1. Define the single communication goal.
2. Identify the first visual focus: title, key number, product image, CTA, logo, person, light, blank space, or another attention anchor.
3. Map the reading path: first eye, second eye, third eye, final action or takeaway.
4. Choose a dominant shape language: geometric, organic, random/experimental, or a deliberate mix.
5. Build spatial layers: foreground for core message/action, midground for evidence/content, background for atmosphere or brand support.
6. Remove every element that does not help focus, guide, identify, group, or clarify space.
7. Validate with the 3-second test, thumbnail test, grayscale test, and path test when practical.

## Review Lens
Lead with actionable findings. Diagnose visual problems in this order:

1. Point: Is there one clear first focus, or are multiple elements competing?
2. Line: Does the eye move in the intended order, or is the reading path broken?
3. Shape: Are repeated components and symbols consistent, memorable, and semantically aligned?
4. Form: Are foreground, midground, background, shadow, depth, and white space clarifying hierarchy?
5. Deletion: Which decorative or redundant elements can be removed without weakening meaning?

For each issue, explain the likely user perception and the concrete design change.


```markdown

## 修改建议
```
