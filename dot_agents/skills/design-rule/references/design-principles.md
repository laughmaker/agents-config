# 系统设计原则：从点、线、形状、形体建立可复用的视觉秩序
> 适用范围：PPT、网页、海报、平面设计、品牌视觉、信息图、产品界面  
> 核心命题：设计不是装饰版面，而是用视觉语言组织注意力、阅读路径、识别记忆和空间层级。

## 0. 总原则：先建立视觉秩序，再追求风格
一个设计作品无论最后呈现为 PPT、网页、海报还是品牌物料，本质上都要解决四个问题：
| 问题 | 对应视觉语言 | 设计任务 | 用户结果 |
|---|---|---|---|
| 第一眼看哪里？ | 点 Point | 聚焦注意力 | 用户立刻抓住重点 |
| 接下来怎么看？ | 线 Line | 引导阅读路径 | 用户顺着设计理解信息 |
| 记住什么轮廓？ | 形状 Shape | 建立识别与语义 | 用户形成清晰记忆 |
| 信息如何分层？ | 形体 Form | 创造空间与层次 | 用户理解主次、前后和关系 |
这四层不是孤立技巧，而是一条完整的视觉传达链：
**点抓住注意力 → 线安排视线 → 形状形成识别 → 形体建立空间。**
做设计时，不要先问“怎么做得好看”，而要先问：
1. 我希望观众第一眼看到什么？
2. 我希望观众第二眼、第三眼按什么顺序阅读？
3. 我希望观众离开后记住哪个轮廓、图形或结构？
4. 我希望观众如何理解信息的主次、前后、归属和距离？
如果这四个问题没有答案，字体、配色、图片、动效和装饰都会变成随机堆叠。

## 1. 点 Point：设计从一个明确焦点开始
点不是一个小圆点，而是画面中最先获得注意力的位置。它可以是标题、数字、产品、人物眼睛、按钮、Logo、灯光、图标、色块、空白区域，也可以是重复点阵里的一个异常点。

## 1.1 点的定义
从几何角度看，点没有长度、宽度和面积，它只是一个位置。从设计角度看，点是注意力的锚点。只要一个元素能让观众第一眼停留，它就承担了“点”的功能。
点的关键不是形态，而是结果：
| 常见形式 | 为什么它能成为点 | 适用场景 |
|---|---|---|
| 标题 | 字号、位置、语义最强 | PPT 结论页、网页首屏、海报主标题 |
| 关键数字 | 高信息密度，容易被记住 | 数据页、融资页、增长页、转化页 |
| 产品图 | 具象、易理解、可形成记忆 | 产品页、电商页、品牌海报 |
| 人物眼睛 | 人类天然会追随视线 | 访谈页、人物页、公益海报 |
| CTA 按钮 | 代表下一步行动 | 网页、App、落地页 |
| Logo | 代表品牌身份 | 封面页、品牌物料、活动视觉 |
| 留白 | 通过周围空出来制造停顿 | 高级感页面、极简海报、重点强调 |
| 光源/亮点 | 高明度对比天然吸睛 | 摄影、产品渲染、舞台视觉 |

## 1.2 点的核心原则
**每一屏、每一页、每一个版面，都必须先确定一个第一视觉焦点。**
人的眼睛不会平均浏览画面。观众打开一个页面时，会先看到一个地方，再继续移动。设计师真正控制的不是版面本身，而是观众注意力的落点。
因此，开始设计前先问一句：
**如果观众只停留 3 秒，他第一眼应该看到什么？**
这个问题比“用什么字体”“配什么颜色”“放什么装饰”更重要。焦点一旦确定，尺寸、位置、色彩、留白、动线和层级才有判断依据。

## 1.3 点的设计方法
### 1.3.1 用对比制造焦点
点来自差异。没有差异，就没有焦点。
常用对比方式：
| 对比方式 | 做法 | 注意事项 |
|---|---|---|
| 尺寸对比 | 让核心元素明显更大 | 大不等于乱，要保留边界和呼吸 |
| 明暗对比 | 亮背景放暗点，暗背景放亮点 | 不要让多个亮点同时竞争 |
| 色彩对比 | 用主色或强调色突出核心 | 强调色最好只服务一个重点 |
| 密度对比 | 在稀疏区域放一个密集元素，或反过来 | 适合海报、封面和信息图 |
| 位置对比 | 把核心放在视觉重心或非常规位置 | 偏离中心时要用线和留白稳定版面 |
| 形态对比 | 一组方形中放圆形，一组规则中放不规则 | 异常点必须有信息意义 |

### 1.3.2 用留白放大焦点
留白不是空，而是帮助观众停下来的空间。一个元素周围越干净，它越容易成为点。
应用方法：
- PPT 封面可以只保留标题、关键词和一个视觉锚点。
- 网页首屏不要把所有卖点、按钮、标签和公告都塞到同一屏。
- 海报中重点元素周围留出安静区域，比给它加描边更有效。
- 图表中关键数据附近减少网格、辅助线和标签，直接提高可读性。

### 1.3.3 用重复点形成纹理和节奏
单个点可以形成焦点，多个点可以形成图案、纹理、节奏和密度变化。图片页中的点阵案例说明：点虽然最小，但通过排列、疏密、大小和方向，可以形成完整画面。
应用方法：
- 用点阵表达科技、系统、数据、星图、粒子、扩散、网络。
- 用头像、Logo、图标的重复表达社区、用户、客户案例。
- 用小圆点或节点表达步骤、时间轴、流程状态。
- 用一个被强调的点表达“当前”“重点”“异常”“机会”。
注意：点阵不是背景装饰，最好服务一个明确含义，例如“扩散”“聚合”“增长”“连接”“样本”。

## 1.4 点在不同媒介中的用法
### PPT
- 一页只设置一个第一焦点：标题、关键数字、产品图、结论句四选一。
- 如果有图表，焦点应落在关键数据或结论标注，而不是整个图表。
- 页码、Logo、脚注必须降低权重，不能抢主焦点。
- 章节页可以用一个巨大数字、关键词或符号作为视觉点。

### 网页
- 首屏只允许一个主行动目标，例如“预约演示”“开始试用”“查看方案”。
- 主 CTA 要成为行动点，但不能比价值主张更早抢走全部注意。
- 产品截图中的高亮区域应对应页面文案，不要随意发光。
- 导航、促销条、悬浮按钮、弹窗不要同时争夺第一眼。

### 平面设计
- 海报需要一个远距离也能看见的主点。
- 包装需要一个货架上能被认出的主视觉点。
- 品牌物料需要一个可重复出现的识别点，例如符号、色块、图形模块。
- 公益广告常用人物、眼睛、伤口、物件或反常细节作为情绪焦点。

## 1.5 点的常见错误
| 错误 | 表现 | 修正 |
|---|---|---|
| 多焦点竞争 | 标题、图片、按钮、标签都很醒目 | 选一个主点，其余降级 |
| 焦点与目标不一致 | 第一眼看到装饰，而不是核心信息 | 让焦点服务页面目标 |
| 焦点太弱 | 缩略图看不出重点 | 增加尺寸、对比、留白或位置优势 |
| 焦点太孤立 | 看到了重点，但不知道下一步 | 用线建立后续阅读路径 |
| 为了点而点 | 加了装饰圆点、贴纸、光斑但没有意义 | 删除无功能点 |

## 2. 线 Line：线不是连接两个点，而是控制视线运动
线是移动的点留下的痕迹。设计里的线不只是一条画出来的线，它更是一种阅读路径、空间边界、信息关系和情绪节奏。

## 2.1 线的定义
线可以有形，也可以无形。
| 线的类型 | 例子 | 作用 |
|---|---|---|
| 实线 | 分割线、连接线、箭头、时间轴 | 明确连接、分隔、方向 |
| 隐形线 | 对齐、网格、文字排列、图片边缘 | 形成秩序和阅读路径 |
| 视线 | 人物目光、手势方向、产品朝向 | 引导注意力 |
| 透视线 | 道路、建筑边缘、空间延伸 | 制造深度和方向 |
| 光影线 | 光束、阴影边缘、明暗走向 | 营造氛围和视觉流动 |
| 节奏线 | 重复元素、波形、曲线、阶梯 | 表达节奏、运动和情绪 |

线的价值不在于“画出来”，而在于让观众自然地从一个信息点移动到下一个信息点。

## 2.2 线的核心原则
**信息的视觉顺序，必须匹配用户理解信息的顺序。**
一张设计如果让观众不知道下一眼看哪里，即使每个局部都很好看，整体也是失败的。好的线会让用户不知不觉按设计师预设的路径阅读。
常见阅读路径：
| 路径 | 适合场景 | 设计要点 |
|---|---|---|
| 上到下 | 长网页、报告页、移动端 | 信息分段清楚，首尾行动明确 |
| 左到右 | 横版 PPT、对比页、流程图 | 左侧给结论或问题，右侧给证据或答案 |
| 中心向外 | 品牌海报、概念图、产品亮相 | 中心必须足够强，外围不能抢焦点 |
| Z 型 | 网页首屏、营销页 | 左上价值主张，右侧视觉，右下行动 |
| F 型 | 内容型网页、列表页 | 标题和小标题要形成清晰扫描线 |
| 时间轴 | 历史、路线图、项目计划 | 节点密度和节奏要可读 |
| 放射型 | 系统图、生态图、网络关系 | 中心和连接关系必须明确 |

## 2.3 线的设计方法
### 2.3.1 用对齐建立隐形线
对齐是最基本、最可靠的线。很多设计不需要画线，只要让标题、正文、图片、按钮、图表边缘形成稳定对齐，秩序就会出现。
应用方法：
- PPT 每页建立固定左边界、标题线、图表线和脚注线。
- 网页卡片中的标题、图标、按钮要共享基准线。
- 海报里文字组和图片边缘要形成可感知的垂直或水平关系。
- 图表标注要贴近对应对象，减少跨画面的视线跳跃。

### 2.3.2 用方向组织阅读
线会带来运动感。横线稳定，竖线挺拔，斜线动态，曲线柔和，折线紧张。
| 线型 | 常见感受 | 适用 |
|---|---|---|
| 横线 | 稳定、安静、广阔 | 数据分组、目录、内容分隔 |
| 竖线 | 上升、庄重、力量 | 时间轴、组织结构、建筑感页面 |
| 斜线 | 速度、张力、变化 | 活动海报、运动品牌、增长表达 |
| 曲线 | 柔和、流动、自然 | 生活方式、健康、情绪表达 |
| 折线 | 冲突、转折、节奏 | 战略变化、风险、问题诊断 |
| 虚线 | 暗示、未完成、路径 | 流程预告、关系弱连接、辅助说明 |

### 2.3.3 用线让复杂信息变简单
图片页中的时间轴、线路图、信息图案例说明：线可以把分散信息串成连续路径，让复杂内容一眼可读。
应用方法：
- 讲历史：用时间线，而不是堆日期。
- 讲流程：用步骤线，而不是散放模块。
- 讲系统：用连接线表达输入、处理、输出。
- 讲对比：用中心轴或分栏线建立两侧关系。
- 讲路线：用路径线表达用户旅程、销售漏斗、决策过程。

### 2.3.4 用线表达情绪和品牌
线条的材质、粗细、连续性和笔触会传递情绪。图片页中的 SAFE 字母案例强调了这一点：同样是线，笔触不同，情绪完全不同。
应用方法：
- 细线：精致、理性、科技、轻盈。
- 粗线：力量、直接、年轻、强识别。
- 手写线：温度、人味、非正式、创意。
- 断裂线：破损、风险、不确定。
- 连续线：流动、连接、完整性。
- 几何线：秩序、专业、系统。
不要只把线当分隔符。线可以是品牌资产，例如固定的曲线、路径、边框、转角、波形、扫描线或网格系统。

## 2.4 线在不同媒介中的用法
### PPT
- 一页只采用一种主要阅读方向。
- 结论页可以用“标题 → 关键数字 → 解释 → 证据”的路径。
- 流程页使用连续线或编号节点，不要让步骤散落。
- 对比页使用中心轴、左右分栏或上下分层，避免观众不知道先看哪边。
- 图表页用标注线聚焦关键变化，但不要把所有数据都标出来。

### 网页
- 首屏可用 Z 型路径：左侧价值主张、右侧产品视觉、下方行动。
- 长页面要用章节线索：标题、间距、背景分区、导航锚点。
- 卡片列表要保持同一对齐线，否则用户扫描成本会升高。
- 人物图片的视线、产品截图的方向、箭头和动效都应指向行动或重点。

### 平面设计
- 海报中的人物目光、道路延伸、建筑边缘、光线方向都能引导阅读。
- 品牌视觉可用固定线条语言建立识别，如连续线、波形、网格、路径。
- 宣传册和画册要用基线、栏宽、边距形成稳定阅读节奏。
- 信息图优先用线表达时间、因果、流向和连接关系。

## 2.5 线的常见错误
| 错误 | 表现 | 修正 |
|---|---|---|
| 线只做装饰 | 画了很多分隔线，但没有信息关系 | 每条线必须连接、分隔、引导或表达情绪 |
| 路径冲突 | 箭头、人物视线、排版方向互相打架 | 统一主阅读方向 |
| 线太重 | 分隔线比内容更抢眼 | 降低颜色、粗细或改成留白分隔 |
| 隐形线断裂 | 标题、正文、图片没有对齐 | 建立统一网格 |
| 过度依赖箭头 | 不画箭头就读不懂 | 先用位置、大小、对齐解决路径 |

## 3. 形状 Shape：形状让信息被识别、被分类、被记住
如果说点是视觉起点，线是视觉运动，形状就是设计真正开始表达信息的第一步。形状是由边界包围的二维平面，它拥有轮廓、面积和气质。

## 3.1 形状的定义
形状通常指由轮廓围合形成的二维图形。点放大可以成为形状，线首尾相连也可以形成形状。
形状的价值包括：
- 识别：让用户快速认出一个品牌、图标、模块或类别。
- 组织：把信息放进可理解的区域。
- 引导：通过大小、方向、位置引导注意力。
- 情绪：在文字之前传达气质。
- 记忆：形成可复述、可联想、可重复的视觉符号。

## 3.2 面、留白与视觉重量
图片页强调“面就是信息分组”“面与留白”“面的视觉重量”。这对实用设计非常重要。
| 概念 | 含义 | 设计用法 |
|---|---|---|
| 面 | 被边界、颜色、留白或内容密度定义出的区域 | 分组、承载内容、形成版块 |
| 留白 | 没有元素但有结构意义的空间 | 分隔、强调、制造呼吸感 |
| 视觉重量 | 元素在画面中吸引注意的强度 | 决定主次、平衡和焦点 |
视觉重量由尺寸、颜色、位置、密度、形状复杂度、明暗和周围留白共同决定。一个小黑点在大面积白底上可能比一个灰色大块更有重量。

## 3.3 三类基础形状
| 类型 | 特征 | 气质 | 适合场景 |
|---|---|---|---|
| 几何形 | 圆、方、三角、线性规则明确 | 理性、稳定、秩序、效率 | 科技、金融、SaaS、数据、咨询、教育 |
| 有机形 | 来自自然，边缘柔和、不完全规则 | 亲和、生命力、自然、温暖 | 健康、宠物、食品、环保、生活方式 |
| 随机形 | 不规则、实验性、自由组合 | 创意、个性、潮流、艺术、冲突 | 展览、活动、文化、音乐、青年品牌 |
它们不是固定公式，而是判断起点。真正设计时要看内容语义、品牌人格和受众预期。

## 3.4 常见基础形状的语义
| 形状 | 常见联想 | 使用建议 |
|---|---|---|
| 圆形 | 包容、完整、循环、柔和、关系 | 适合社区、健康、生态、用户关系 |
| 方形 | 稳定、秩序、可靠、边界、模块 | 适合企业、工具、数据、系统页面 |
| 三角形 | 方向、力量、速度、冲突、上升 | 适合增长、战略、运动、警示 |
| 星形 | 荣誉、突出、活动、庆祝 | 适合奖项、推荐、促销，但容易显得廉价 |
| 箭头 | 方向、行动、进展、转化 | 适合流程和 CTA，但不要滥用 |
| 波形 | 流动、声音、节奏、柔和 | 适合音频、健康、自然、服务体验 |
| 网格 | 系统、秩序、规模、理性 | 适合数据、平台、产品架构 |
| 不规则块 | 个性、实验、松弛、手作感 | 适合创意场景，商业严肃内容慎用 |

## 3.5 形状的核心原则
**把复杂信息压缩成简单、稳定、可复用的轮廓。**
用户很多时候记住的不是颜色和文字，而是轮廓。优秀 Logo、图标、包装、海报主视觉都依赖这一点。
实用判断：
- 去掉文字后，用户还能否理解分类？
- 缩小到手机屏或 PPT 缩略图后，轮廓是否仍清晰？
- 只看剪影，品牌或主题是否还可辨认？
- 同类内容是否使用了同一种形状语言？
- 形状是否真的承载含义，而不是随意装饰？

## 3.6 形状与空间
形状不只决定轮廓，也决定版面的空间关系。
应用方法：
- 用大形状定义主内容区。
- 用小形状承载标签、按钮、编号和提示。
- 用相同形状表达同类，用不同形状表达差异。
- 用形状的重叠表达关系，用分离表达独立。
- 用形状的方向表达运动或转化。
- 用形状的留白表达高级感和重要性。
注意：每个形状都会占用视觉注意力。形状越多，用户越难判断主次。

## 3.7 形状的品牌原则
图片页中的 MAD、MUJI、Nike、Tesla、NYC 等案例说明：优秀品牌往往有强形状识别。Logo 不是漂亮图案，而是能长期被记住、被扩展、被复制的形状系统。
品牌形状要满足：
- 简单：缩小后仍清楚。
- 独特：不依赖复杂细节也能被认出。
- 可扩展：能用于 Logo、图标、版式、包装、动画和空间。
- 有语义：形状气质与品牌内容一致。
- 可组合：能形成一套设计语言，而不是孤立标志。

## 3.8 形状在不同媒介中的用法
### PPT
- 用统一形状承载同级信息，例如所有观点卡片都是同一种容器。
- 用形状差异表达不同类型，例如问题用三角警示，结论用圆形强调，数据用方形模块。
- 图示先拆成基础几何，再组合成结构图。
- 一套 PPT 不要频繁切换圆角、斜切、胶囊、气泡、贴纸等风格。

### 网页
- 按组件系统管理形状：按钮、卡片、输入框、标签、弹窗要有统一圆角和边框逻辑。
- 产品截图和插图中的形状语言要与 UI 组件一致。
- 图标必须保留清晰剪影，避免过细、过复杂。
- 不要为了“丰富”给每个模块设计不同容器。

### 平面设计
- 海报主视觉最好有一个远距离可识别的大轮廓。
- 包装设计应考虑货架识别，而不只是近距离精致。
- 画册和宣传页可用固定图形模块建立连续性。
- 活动视觉可以更自由，但仍需要主形状统一整套物料。

## 3.9 形状的常见错误
| 错误 | 表现 | 修正 |
|---|---|---|
| 形状太多 | 每块内容都是不同造型 | 建立主形状、辅助形状和禁用形状 |
| 形状无语义 | 只是为了填空或好看 | 让形状承担分类、强调或品牌作用 |
| 轮廓不清 | 缩小后看不出来 | 简化边界，减少细节 |
| 风格冲突 | 科技内容用了过多手绘随机形 | 匹配内容气质 |
| 只做外观 | 容器好看但信息层级混乱 | 先分组，再造型 |

## 4. 形体 Form：形体让二维画面拥有空间、层次和呼吸
形状属于二维，形体属于三维。圆形、方形、三角形是形状；球体、立方体、圆柱体是形体。当平面图形拥有体积、厚度、透视和空间关系，它就从形状变成形体。

## 4.1 形体的定义
形体拥有长、宽、高。设计中的形体分为两类：
| 类型 | 含义 | 例子 |
|---|---|---|
| 真实形体 | 真实世界中具有体积的物体 | 建筑、家具、包装、产品、雕塑 |
| 视觉形体 | 在二维画面中制造三维错觉 | 投影、透视、渐变、遮挡、光影、3D 插图 |
形体不是为了让画面“看起来高级”，而是为了表达空间关系：谁在前，谁在后，谁更重要，谁属于谁，谁离用户更近。

## 4.2 形状与形体的区别
| 维度 | 形状 Shape | 形体 Form |
|---|---|---|
| 空间 | 二维 | 三维或三维错觉 |
| 构成 | 轮廓、边界、面积 | 体积、厚度、透视、光影 |
| 任务 | 识别、分类、语义 | 层级、空间、前后、质感 |
| 问题 | 它是什么形？ | 它如何占据空间？ |
| 常用手段 | 圆、方、三角、不规则形 | 遮挡、投影、渐变、明暗、透视 |
一句话：**形状决定轮廓，形体决定空间。**

## 4.3 形体由什么形成
图片页把形体的形成拆成几个关键手段：
| 手段 | 作用 | 使用建议 |
|---|---|---|
| 光影 | 显示体积和方向 | 光源方向要统一 |
| 明暗 | 建立凸起、凹陷、转折 | 避免无意义渐变 |
| 投影 | 表达悬浮、距离、层级 | 阴影越多不代表越高级 |
| 透视 | 制造深度和空间延伸 | 适合建筑、产品、场景图 |
| 遮挡 | 表达前后关系 | 前景不能挡住关键信息 |
| 厚度 | 让平面元素变成立体对象 | 用于强调按钮、卡片、图形模块 |
| 材质 | 传递质感和真实度 | 只在内容需要质感时使用 |
| 留白 | 创造空间和呼吸 | 是空间关系的一部分 |

## 4.4 形体的核心原则
**用空间关系表达信息层级，而不是用立体效果装饰画面。**
很多设计误区是：为了“高级”，给所有卡片加阴影，给所有图标做 3D，给图表做透视。但如果形体没有解释信息关系，它就只是视觉噪声。
正确用法：
- 用悬浮表达可点击、可操作。
- 用遮挡表达前后关系。
- 用大小和距离表达主次。
- 用光影表达物体体积或空间方向。
- 用前景、中景、背景表达叙事层次。
- 用留白让层级之间有呼吸感。

## 4.5 形体与虚实
图片页区分“真实形体 VS 视觉形体”。这对设计判断很实用：
| 设计对象 | 更适合真实形体 | 更适合视觉形体 |
|---|---|---|
| 产品展示 | 产品照片、渲染图、包装实拍 | 辅助高亮、热点标注 |
| 品牌海报 | 场景摄影、真实物件 | 抽象 3D 图形、空间错觉 |
| PPT 汇报 | 真实产品、用户、场景证据 | 概念模型、结构图、层级关系 |
| 网页首屏 | 产品界面、设备框、使用场景 | 背景空间、组件层级、动效 |
| 信息图 | 实物关系或地理空间 | 流程、层级、系统结构 |
经验规则：如果内容需要可信度，优先真实形体；如果内容需要解释抽象关系，优先视觉形体。

## 4.6 形体的设计方法
### 4.6.1 建立前景、中景、背景
复杂页面要分层，而不是把所有元素放在同一平面。
| 层级 | 作用 | 常见元素 |
|---|---|---|
| 前景 | 当前重点、行动、结论 | CTA、关键数字、主标题、重点标注 |
| 中景 | 主要内容和证据 | 图表、卡片、产品图、正文 |
| 背景 | 氛围、空间、品牌识别 | 大色块、网格、弱纹理、场景图 |
注意：背景应该托住内容，而不是抢走内容。

### 4.6.2 控制光源和投影
只要使用投影、渐变或 3D 元素，就必须假设一个统一光源。
检查方法：
- 阴影方向是否一致？
- 高光是否来自同一侧？
- 元素悬浮高度是否有层级逻辑？
- 阴影是否过黑、过脏、过厚？
- 去掉阴影后，信息结构是否仍然成立？

### 4.6.3 用空间引导阅读
空间不只是深度，也能引导视线。
应用方法：
- 把最重要信息放在最近、最大、最清晰的位置。
- 把辅助信息放在中景，用较弱对比承接阅读。
- 把装饰和氛围放在背景，降低透明度和细节。
- 用透视线、台阶、路径、光源方向引导到重点。
- 用遮挡让画面有前后，但不要遮挡文本和关键信息。

### 4.6.4 让设计有呼吸感
图片页强调“形体与空间关系，让设计更有呼吸感”。呼吸感不是元素少，而是主次、距离和空白合理。
实用规则：
- 内容越重要，周围越需要留白。
- 同一组内容靠近，不同组内容分开。
- 大元素周围留大空间，小元素不能散成噪声。
- 背景层不要放太多高对比细节。
- 版面边缘要留出安全距离，避免压迫感。

## 4.7 形体在不同媒介中的用法
### PPT
- 复杂汇报页用三层结构：结论在前景，图表在中景，背景保持安静。
- 不要使用 3D 饼图、透视柱状图等损害数据可读性的效果。
- 产品页可以用真实产品渲染建立可信度。
- 战略模型可以用层叠、台阶、金字塔、飞轮表达空间关系。

### 网页
- 页面层级要稳定：底层页面、卡片、浮层、弹窗、Toast、菜单不能阴影混乱。
- 按钮的形体暗示可点击，但不要把所有按钮都做得很“凸”。
- 产品截图可以使用轻微透视，但文字和关键 UI 必须可读。
- 3D 视觉要服务产品理解，不要只是首屏装饰。

### 平面设计
- 海报可以用光影、透视和遮挡制造戏剧性。
- 包装设计必须考虑真实物体的体积、折面、货架角度和拍摄光影。
- 画册中图片的大小、裁切和留白会形成空间节奏。
- 建筑、家具、产品类设计应优先尊重真实形体的比例和材质。

## 4.8 形体的常见错误
| 错误 | 表现 | 修正 |
|---|---|---|
| 为立体而立体 | 所有元素都有阴影、渐变、透视 | 只给需要表达层级的元素加形体 |
| 光源混乱 | 阴影方向不一致 | 统一光源 |
| 空间层级不清 | 前景、背景都很抢眼 | 降低背景对比，提高主内容清晰度 |
| 遮挡伤害可读性 | 图形挡住文字或数据 | 先保证信息，再考虑空间效果 |
| 质感过度 | 材质、反光、阴影太多 | 保留必要质感，删除炫技效果 |

## 5. 四种语言如何协同
真正成熟的设计不是分别使用点、线、形状、形体，而是让它们共同工作。

## 5.1 一个页面的协同公式
可以把任意设计页拆成下面这条公式：
**目标信息 = 一个焦点 + 一条路径 + 一套形状 + 一个空间层级**
| 层级 | 设计动作 | 输出物 |
|---|---|---|
| 点 | 选出第一视觉焦点 | 主标题、关键数字、主图、CTA |
| 线 | 安排阅读顺序 | 网格、路径、流程、对齐、方向 |
| 形状 | 定义信息容器和识别 | 卡片、图标、图形、Logo、模块 |
| 形体 | 建立空间和层级 | 前中后景、阴影、遮挡、留白 |

## 5.2 从抽象到具体的设计顺序
推荐每次按这个顺序做：
1. 写出唯一目标。
2. 选择第一焦点。
3. 规划阅读路径。
4. 划分信息区域。
5. 选择主形状语言。
6. 建立前中后景层级。
7. 加入字体、颜色、图片和动效。
8. 删除不服务信息的元素。
这个顺序很重要。不要在焦点和路径还没确定时先调色、找字体、加纹理。那会让设计看起来丰富，但信息更混乱。

## 5.3 四层之间的常见冲突
| 冲突 | 典型表现 | 解决方式 |
|---|---|---|
| 点与线冲突 | 焦点很强，但路径把视线引向别处 | 调整方向、对齐和人物视线 |
| 点与形状冲突 | 装饰形状比核心内容更醒目 | 降低装饰面积、颜色或对比 |
| 线与形状冲突 | 容器很多但阅读顺序不清 | 用统一网格和编号路径重组 |
| 形状与形体冲突 | 轮廓清楚但空间效果过度 | 减少投影、透视和材质 |
| 形体与内容冲突 | 3D 效果好看但文字难读 | 回到信息可读性 |

## 6. 面向 PPT 的实用原则
PPT 的核心不是“把资料放上去”，而是让观众按你的顺序理解一个观点。每一页 PPT 都应该像一个小型信息系统。

## 6.1 PPT 单页原则
| 原则 | 做法 |
|---|---|
| 一页一焦点 | 每页只让一个结论、数字、图像或模型成为第一眼 |
| 标题即结论 | 标题尽量写判断，不只写主题 |
| 先路径后排版 | 先决定观众按什么顺序看，再摆元素 |
| 图表有主点 | 标出最重要的数据，不让观众自己找 |
| 模型有形状 | 用稳定形状表达结构，而不是堆文本框 |
| 空间分层 | 结论、证据、解释、备注必须有层级 |
| 少即是清楚 | 能删的辅助元素尽量删 |

## 6.2 常见 PPT 页面模板
### 封面页
- 点：标题或主视觉。
- 线：副标题、日期、作者形成安静的阅读路径。
- 形状：品牌主形状或项目符号。
- 形体：背景留白或真实场景建立气质。
检查：缩略图里是否一眼知道主题？

### 结论页
- 点：一句核心判断。
- 线：判断 → 3 个理由 → 下一步。
- 形状：3 个理由使用统一模块。
- 形体：核心判断在前景，理由在中景。
检查：只看标题是否能知道你的观点？

### 数据页
- 点：最关键的数据变化。
- 线：标题 → 图表 → 标注 → 启示。
- 形状：图表类型保持简洁，不用多余容器。
- 形体：重点标注浮在图表上方，但不遮挡数据。
检查：观众是否不用解释就能找到关键变化？

### 流程页
- 点：当前阶段或最终目标。
- 线：流程路径必须连续。
- 形状：每个步骤用同类节点。
- 形体：当前步骤可通过前景、明暗或尺寸突出。
检查：流程是否能从起点顺到终点？

### 对比页
- 点：最关键差异。
- 线：左右或上下形成稳定比较路径。
- 形状：两侧容器必须一致，避免视觉偏见。
- 形体：重要一侧可以略前置，但不要失衡。
检查：差异是否比装饰更明显？

## 7. 面向网页设计的实用原则
网页设计的核心是让用户快速理解价值、建立信任并完成下一步行动。

## 7.1 网页页面原则
| 原则 | 做法 |
|---|---|
| 首屏有唯一主点 | 标题、产品图、CTA 三者必须有主次 |
| 路径服务转化 | 价值主张 → 证据 → 功能 → 案例 → 行动 |
| 组件形状统一 | 按钮、卡片、输入框、标签要有系统 |
| 层级状态清楚 | 页面、弹窗、下拉、Toast、悬浮按钮层级不能混乱 |
| 留白决定节奏 | 用留白分区，不要只靠线条和色块 |
| 视觉资产真实 | 产品、场景、人物、截图要能说明实际内容 |

## 7.2 网页首屏公式
一个有效首屏通常包括：
1. 第一焦点：清楚的价值主张或产品视觉。
2. 阅读路径：标题 → 解释 → 证据 → CTA。
3. 识别形状：品牌 Logo、组件形状、产品截图轮廓。
4. 空间层级：前景行动、中景内容、背景氛围。
检查问题：
- 用户 3 秒内知道这是做什么的吗？
- 主 CTA 是否清楚但不压过价值主张？
- 产品图是否真实表达产品，而不是纯装饰？
- 导航、公告、弹窗是否抢走首屏焦点？

## 7.3 网页组件系统
组件本质上是形状系统。每种组件都要有明确角色：
| 组件 | 点 | 线 | 形状 | 形体 |
|---|---|---|---|---|
| 按钮 | 行动焦点 | 指向下一步 | 固定圆角和尺寸 | 可点击层级 |
| 卡片 | 局部信息焦点 | 扫描顺序 | 内容容器 | 与背景分离 |
| 导航 | 方向焦点 | 页面路径 | 标签/菜单形状 | 当前层级 |
| 表单 | 输入焦点 | 填写顺序 | 输入框系统 | 状态反馈 |
| 弹窗 | 临时焦点 | 决策路径 | 对话容器 | 前景遮罩 |
| 图表 | 数据焦点 | 读图顺序 | 图形编码 | 标注层级 |

## 8. 面向平面设计的实用原则
平面设计更强调远距离识别、瞬间情绪和媒介适配。

## 8.1 海报
- 点：远距离第一眼能看见的主视觉或主标题。
- 线：人物视线、图形方向、文字排列引导阅读。
- 形状：主视觉要有强剪影。
- 形体：通过光影、遮挡、透视制造戏剧性。
检查：站远一点看，是否还能识别主题？

## 8.2 品牌视觉
- 点：品牌最小识别单元，例如 Logo、符号、色块、图形角。
- 线：品牌专属线条语言，例如网格、路径、波形、连续线。
- 形状：可重复使用的主形状系统。
- 形体：产品、空间、包装和数字界面中的统一层级。
检查：去掉品牌名后，这套视觉还像同一个品牌吗？

## 8.3 包装与物料
- 点：货架上最先被看见的品牌或产品特征。
- 线：阅读顺序从品牌、品类、卖点到规格。
- 形状：包装轮廓和图形模块要易识别。
- 形体：考虑真实体积、折面、拍摄角度和光影。
检查：放到同类产品旁边，是否有清晰识别点？

## 9. 通用设计流程
这套流程适合从空白开始，也适合改版现有设计。

## 9.1 第一步：提炼信息
先写清楚，不要先排版。
1. 这个页面/这页 PPT/这张海报的唯一目标是什么？
2. 用户离开后必须记住的一句话是什么？
3. 哪些信息是主信息、支持信息、补充信息？
4. 哪些信息可以延后、折叠或删除？
输出物：一句结论 + 三层信息清单。

## 9.2 第二步：设置点
1. 选择唯一第一焦点。
2. 决定它靠什么获得注意：尺寸、位置、色彩、图像、留白、明暗或异常。
3. 降低其他元素权重。
4. 做 3 秒测试。
输出物：第一视觉焦点。

## 9.3 第三步：连接线
1. 规定阅读起点。
2. 规定第二、第三、第四眼的顺序。
3. 用对齐、间距、方向、重复建立隐形路径。
4. 只有路径不清时才添加可见线或箭头。
输出物：阅读路径图。

## 9.4 第四步：塑造形状
1. 把信息分组。
2. 为同类内容选择统一容器。
3. 选择符合内容气质的主形状。
4. 检查缩略图和剪影。
输出物：形状系统。

## 9.5 第五步：建立形体
1. 区分前景、中景、背景。
2. 用大小、遮挡、光影、明暗、投影、留白建立层级。
3. 统一光源和空间逻辑。
4. 删除无结构意义的立体效果。
输出物：空间层级。

## 9.6 第六步：加入表现层
在基础秩序成立后，再处理：
- 字体：强化语气和层级。
- 色彩：强化焦点、分类和品牌。
- 图片：提供真实证据、情绪和场景。
- 材质：补充触感和真实度。
- 动效：表达状态变化和路径，不要只做炫技。

## 9.7 第七步：删减
逐个元素问：
- 它是否帮助聚焦？
- 它是否帮助引导？
- 它是否帮助识别？
- 它是否帮助分组？
- 它是否帮助建立空间？
如果五个问题都是否，删除。

## 10. 设计检查清单
完成初稿后，用下面清单逐项检查。

## 10.1 点：焦点检查
- [ ] 第一眼只有一个主焦点。
- [ ] 主焦点服务页面目标。
- [ ] 缩略图里仍能看出重点。
- [ ] 留白帮助焦点，而不是浪费空间。
- [ ] 辅助信息没有抢主焦点。

## 10.2 线：路径检查
- [ ] 阅读起点、顺序和终点明确。
- [ ] 对齐关系稳定。
- [ ] 人物视线、图形方向、箭头方向不冲突。
- [ ] 可见线条都有功能。
- [ ] 不画箭头时，路径仍基本成立。

## 10.3 形状：识别检查
- [ ] 同类信息使用一致形状。
- [ ] 核心轮廓缩小后仍清晰。
- [ ] 形状气质符合内容语义。
- [ ] 图标和 Logo 不依赖过多细节。
- [ ] 没有为了填空而加入的图形。

## 10.4 形体：空间检查
- [ ] 前景、中景、背景有明显区别。
- [ ] 阴影、渐变、透视、遮挡都有结构意义。
- [ ] 光源方向统一。
- [ ] 文字和数据没有被空间效果影响可读性。
- [ ] 留白让内容有呼吸感。

## 10.5 整体：结果检查
- [ ] 3 秒内能说出核心信息。
- [ ] 30 秒内能理解主要结构。
- [ ] 看完后能记住一个关键词、轮廓或结论。
- [ ] 视觉风格与内容、品牌、受众一致。
- [ ] 删除装饰后，设计依然成立。

## 11. 常用测试方法
### 3 秒测试
把设计给别人看 3 秒，然后收起来，问：
- 你第一眼看到了什么？
- 你觉得这页主要想说什么？
- 你下一步想点击/阅读哪里？
如果答案与你预期不一致，先调整点和线。

### 缩略图测试
把页面缩到 25% 或在文件缩略图里看：
- 主焦点是否还在？
- 轮廓是否还清楚？
- 层级是否还可辨？
如果缩小后糊成一团，说明形状和空间层级不够清楚。

### 灰度测试
去掉颜色，只看黑白灰：
- 焦点是否仍成立？
- 层级是否仍成立？
- 图表是否仍可读？
如果去色后完全失效，说明设计过度依赖颜色，对比和结构不够。

### 遮挡测试
遮住一部分元素：
- 是否能推断整体结构？
- 是否有信息过度依赖单一元素？
- 是否有可删除内容？
这适合检查形状系统和信息冗余。

### 远距测试
站远看海报，或把 PPT 投到屏幕上：
- 标题是否可读？
- 主视觉是否可识别？
- 层级是否清楚？
这能发现细节过多、焦点过弱和对比不足的问题。

## 13. 常见设计场景的快速决策
| 场景 | 点 | 线 | 形状 | 形体 |
|---|---|---|---|---|
| 产品发布 PPT | 产品图或发布结论 | 结论到卖点到证据 | 产品轮廓和卖点模块 | 产品在前，证据在后 |
| 融资路演 | 关键增长数字 | 问题到方案到市场到牵引 | 稳定几何模块 | 数据和故事分层 |
| SaaS 官网 | 价值主张或产品截图 | 首屏到证据到 CTA | 组件系统和图标 | 页面、卡片、浮层层级 |
| 活动海报 | 活动名或主视觉 | 标题到时间地点到行动 | 强识别符号 | 光影和透视制造现场感 |
| 品牌 Logo | 最小识别点 | 形状延展路径 | 独特轮廓 | 可扩展到空间和物料 |
| 数据报告 | 关键结论或异常值 | 结论到图表到解释 | 图表编码 | 标注浮层和主次空间 |
| 电商包装 | 品牌名或产品特征 | 品牌到品类到卖点 | 包装轮廓和图形系统 | 真实体积和货架光影 |

## 14. 反向诊断：设计不好时先查哪里
| 症状 | 优先检查 | 可能原因 |
|---|---|---|
| 看起来散 | 点 | 没有第一焦点，所有元素权重接近 |
| 看起来乱 | 线 | 阅读路径冲突，对齐关系断裂 |
| 看起来普通 | 形状 | 没有独特轮廓和可记忆符号 |
| 看起来扁 | 形体 | 缺少前后、主次和空间层级 |
| 看起来花 | 删减 | 装饰多于信息功能 |
| 看起来不专业 | 系统 | 字体、颜色、形状、空间规则不统一 |
| 看起来高级但读不懂 | 信息 | 表现层压过内容结构 |

## 15. 一句话原则
**用一个点抓住注意力，用一条线安排阅读，用一种形状留下记忆，用清晰形体建立层次，再删掉所有不服务信息的元素。**
