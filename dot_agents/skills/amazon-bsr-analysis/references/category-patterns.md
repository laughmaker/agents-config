# Category Patterns

## Mixed-shelf rule

Amazon BSR shelves often include items that are adjacent to the target category but not true peers.
Before drawing conclusions, classify each row into a shelf type.

Common non-core row types:

- accessories
- refill SKUs
- scanners/readers
- alternate device classes
- remote-control products
- bundles that distort price

## Pet location trackers example

Typical mixed types:

- GPS/live tracker
- Find My or bluetooth tag
- microchip scanner
- RF homing tracker
- accessory

Useful fifth sheet:
- `Business Model`

Useful selling-point flags:

- no monthly fee
- subscription or membership
- real-time
- virtual fence
- health or wellness
- waterproof
- iOS / Find My
- Android compatibility

Typical opportunity framing:

- low-fee trust gap
- reliability over feature sprawl
- narrower pet/use-case positioning

## Bark collars example

Typical mixed types:

- auto bark collar
- remote training collar
- refill / spray cartridge
- replacement strap / accessory

Useful fifth sheet:
- `Training Mode`

Useful selling-point flags:

- shock / static
- beep
- vibration
- spray
- rechargeable
- waterproof
- small-dog positioning
- humane wording
- AI claim
- 2-pack offer

Typical opportunity framing:

- humane mainstream lane
- small-dog fit and comfort
- category confusion on the PDP
- clear training philosophy

## When to downgrade confidence

Lower confidence and say so when:

- the raw shelf is heavily polluted
- price parsing is obviously broken
- review evidence is missing
- top listings are dominated by one or two legacy SKUs
- only a partial page set was captured

## Facts vs inferences

Treat these as facts:

- counts
- visible price bands
- visible review counts
- title-visible claims
- which rows were included or excluded

Treat these as inferences:

- demand style
- likely opportunity wedges
- likely user anxieties
- strategic implications of shelf structure
